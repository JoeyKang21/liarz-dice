# Liar's Dice 骰子游戏规则与实现

## 游戏规则（2人对战）

### 骰子规则：
1. 摇骰机制：
   - 每人初始5个骰子
   - 每回合开始时玩家各自摇骰
   - 摇骰结果仅自己可见
   - 使用随机数生成1-6的骰面值

2. 点数计算：
   - 1点为万能骰，可代表任何点数
   - 其他点数(2-6)仅代表自身
   - 计算总数时：
     - 叫1点时：只统计实际1点
     - 叫其他点时：统计实际点数+万能骰

### 叫骰规则：
1. 基础规则：
   - 起喊数量 = 玩家人数+1（2人时需从`3个X`起喊）
   - 每次叫骰必须至少增加：
     - 数量（如3个2→4个2）
     - 或点数（如3个2→3个3）

2. 特殊1点规则：
   - 任何时候都可直接叫`3个1`（无视数量递增规则）
   - 后续叫1点仍需遵循点数递增（如3个1→4个1）
   - 后续1点不再代表任何点数，只代表1点

3. 胜负判定规则：
   - 开盅流程：
     1. 当玩家喊"开"挑战
     2. 双方公开所有骰子
     3. 计算场上符合叫骰条件的骰子总数
   - 胜负判定：
     - 实际总数 ≥ 叫骰数量：叫骰方获胜
     - 实际总数 < 叫骰数量：挑战方获胜
     - 获胜方得1分

4. 程序退出：
   - 游戏结束后可通过界面按钮退出程序

## Python实现框架思路

### 架构调整：
1. Player类新增属性：
   - `score`: 记录玩家得分
   - 移除`dice_count`扣减逻辑

2. LiarsDiceGame类修改：
   - 移除`winning_score`参数
   - `challenge()`方法修改：
     - 返回挑战结果(winner, loser)
   - `make_bid()`新增验证：
     - 首轮叫骰需≥(人数+1)
     - `3个1`的特殊豁免逻辑

3. 流程控制：
   - 每回合结束后显示胜负结果
   - 提供退出游戏按钮
   - 根据当前轮次动态调整起喊数量要求
